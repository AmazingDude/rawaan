# Local font assets

`onest-variable.ttf` is the Rawaan UI and body font. It was sourced from the [official Onest directory in Google Fonts](https://github.com/google/fonts/tree/main/ofl/onest). `thestral-neue-bold.woff2` is the sole display asset, reserved in code for the root landing page’s largest hero headline only; it was sourced from the [Thestral Neue project page](https://xcicero.esad-gv.net/page/thestral/index.php).
